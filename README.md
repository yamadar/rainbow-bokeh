# Rainbow Bokeh

光粒子を集約・拡散できるインタラクティブ Canvas SPA。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev
```

`http://localhost:5184/` が自動で開きます。

## テスト・ビルド

```bash
npm test
npm run build
```

## アーキテクチャ

モジュール構成・設計の詳細は [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md) を参照。
